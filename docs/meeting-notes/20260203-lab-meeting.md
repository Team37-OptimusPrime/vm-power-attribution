## 2. 리소스별 에너지 모델

### CPU
- **이용률 = 에너지** (비례 관계)
- RAPL로 전체 CPU 에너지 측정 가능
- VM별: cgroup 등으로 이용률 분리 → 비례 분배

### GPU
- CPU와 다름: **코어 에너지 + 메모리 에너지** 두 가지
- 코어: 이용률에 비례
- GPU 내 메모리: **할당량에 비례 (상수)** - 안 써도 에너지 소모
- nvidia-smi로 전체 측정, vGPU로 분리 가능 (실험에서는 물리 분리)

### DRAM
- **할당량에 비례** (이용량이 아님!)
- DRAM 리프레시 전력이 대부분
- R/W 에너지는 매우 작아서 무시 가능
- "메모리를 많이 썼네 적게 썼네는 중요한 게 아니고, 많이 받았으면 많이 에너지" - 교수님

### Storage
- **메모리와 정반대**: 안 쓰면 에너지 0 (non-volatile)
- IO량에 비례
- cgroup으로 VM별 IO량 분리 가능
- 데이터시트에서 IO당 에너지 참조

## 3. 실험/검증 방법

### 검증 전략
1. A만 돌림 → B만 돌림 → A+B 동시
2. 분배 결과가 단독 실행과 일치하는지 확인

- IO만 때림 → 스토리지 에너지 분리
- CPU만 stress → CPU 에너지 분리
- 각 컴포넌트를 간접적으로 추출

## 5. GPU 관련

- vGPU는 현재 환경에서 사용 불가
- GPU 2장 있으면 물리 분리로 실험 가능
- 1장이면 프로세스별 nvidia-smi 활용
- nvidia-smi에서 프로세스별 utilization 출력 가능 (정확도 확인 필요)
- PCI passthrough 방식은 한 VM에만 물림
