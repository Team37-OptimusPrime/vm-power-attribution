# Phase 2.0 (Component Isolation) 실험의 가치 및 Memory Power 분석

사용자님께서 제기하신 "Config A~D 실험이 DIMM 측정을 실패했으므로 무의미한 것인가?"에 대한 분석 리포트입니다.

## 1. 결론: 실험은 매우 유의미했습니다. (GPU Hidden Power 발견)

DIMM 측정값(0.25W)이 불안정했던 것은 사실이나, 이 실험을 통해 **전체 전력의 약 34%를 차지하는 'GPU Hidden Power'**를 정확히 찾아냈습니다. 이는 Phase 2의 가장 큰 성과입니다.

* **기존 문제**: GPU 센서값(Chip Power)만으로는 Wall Power와의 괴리(Others)가 64%로 너무 컸음.
* **실험 결과**:
  * Config A(2 GPU) vs Config D(1 GPU) 비교를 통해, GPU 1장 추가 시 **Wall Power가 약 13.6W 증가**함을 확인.
  * 그러나 GPU 센서는 **6.0W 증가**만 보고함.
  * **차이(7.6W)**는 센서에 잡히지 않는 **PCIe 슬롯 + VRM + Fan 전력**임.
* **의의**: 이 7.6W를 찾아냄으로써, Others 항목을 대폭 줄이고(64% -> 30% 수준), 이를 'GPU Power' 항목에 합산하여 모델링의 정확도를 높일 수 있게 되었습니다.

## 2. Memory Power 분석 (왜 0.25W인가?)

### 측정 데이터 다시보기

* **Config A (2 DIMM) - Config B (1 DIMM)** = 44.51W - 44.82W = **-0.31W** (오히려 2개가 더 낮음? 측정 오차 범위)
* **Config D (2 DIMM) - Config C (1 DIMM)** = 30.75W - 31.40W = **-0.65W** (역시 음수)
  * *참고: 위 수치는 평균값이며, `phase2_data_summary.txt`의 교차검증 섹션에서는 특정 런 기준으로 +0.68W, -0.18W 등으로 변동이 컸음.*

### 분석: 왜 측정이 안 되었나? (0.25W가 나온 이유)

1. **측정 오차 및 노이즈 (Resolution Limit)**:
    * 우리가 사용하는 RPICT 센서는 수십 W 단위를 측정합니다.
    * DDR4/5 16GB 메모리의 Idle Power는 통상 **1~2W 내외** (매우 적음)입니다.
    * 시스템 Idle Power(약 45W)의 1~2% 불과한 변화량은, 전압 변동/PSU 효율 변화/센서 노이즈에 묻혀서 **유의미한 'Delta(차이)'로 검출되지 않았습니다.**
    * 즉, "0.25W"라는 값은 실제 메모리 소비전력이 아니라 **"측정 불가능한 수준의 노이즈 평균값"**에 가깝습니다.

2. **교수님의 "비현실적" 판단 근거**:
    * 16GB DIMM이 0.25W만 먹는다는 건 물리적으로 너무 낮은 수치입니다. (보통 대기 상태에서도 Refresh 등으로 인해 수 W 소모)
    * 따라서 측정된 0.25W(노이즈)를 쓰지 말고, **신뢰할 수 있는 데이터시트 스펙 (0.2 W/GB * 16GB = 3.2W)**을 사용하는 것이 논문의 신뢰도를 높이는 '안전한' 선택입니다.

## 3. 요약 및 제안

이 실험은 **"실패한 실험"이 아니라 "한계를 확인하고 중요 변수(GPU)를 찾아낸 실험"**입니다.

* **성공**: GPU Hidden Power (7.6W/card) 규명 -> 에너지 모델의 핵심 오차 원인 해결.
* **한계**: Memory Power는 Wall Meter로 측정하기에는 변화량이 너무 미세함 -> 스펙 값(Coefficient) 사용으로 전략 수정.

따라서 교수님께 결과를 보낼 때, **"메모리는 Wall Meter 측정 한계(노이즈)로 인해 유의미한 Delta가 검출되지 않아, 제안해주신 스펙 기반 상수(0.2 W/GB)를 적용했습니다."** 라고 코멘트를 덧붙이는 것이 가장 정확하고 전문적인 답변이 될 것입니다.
